# README screenshots

These are the existing product screenshots from [bindars.dev](https://bindars.dev),
downloaded on November 7, 2026. The website identifies the app as Bindars 1.6.1
on Linux. They are kept in the repository so the README doesn't depend on the
website's generated asset URLs. The Fountain images are converted from WebP
to PNG; the other images are unchanged.

The README uses light and dark versions through GitHub's supported `<picture>`
element. The light image is the fallback. Keep both versions in sync when
replacing screenshots, and update the version caption in the main README.
